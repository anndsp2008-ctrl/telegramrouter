PATCH RAILWAY - TELEGRAM MEDIA ROUTER

Copie estes itens para a RAIZ do projeto:
- Dockerfile
- .dockerignore
- pasta docker/start.sh

A raiz correta é a mesma pasta onde estão:
- composer.json
- index.php
- worker.php
- app/
- vendor/

Depois faça commit/push para o GitHub e redeploy no Railway.

IMPORTANTE:
1. O arquivo deve se chamar exatamente: Dockerfile
   sem .txt, sem extensão.

2. No Railway, se Root Directory estiver configurado, ele precisa apontar
   exatamente para a pasta que contém o Dockerfile.

3. Configure as variáveis do .env no Railway em Variables. Não envie o .env
   para o GitHub.

4. Adicione um Volume persistente montado em:
   /var/www/html/storage
   Isso preserva a sessão MadelineProto entre deploys/restarts.

5. Esta imagem NÃO instala a extensão PHP ext-psr.
   Ela instala GMP e deixa proc_open disponível.

6. O start.sh inicia o Apache e mantém o worker.php sendo reavaliado.
